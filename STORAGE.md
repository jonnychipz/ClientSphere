# State and storage

The target tenant enforces `publicNetworkAccess=Disabled` on Azure Storage accounts. GitHub-hosted runners cannot reach those data-plane endpoints, so ClientSphere deliberately avoids using Blob Storage for deployment metadata.

- Full `customer-agents.json` metadata is generated by GitHub Actions and embedded in the private application image.
- A gzip/base64 state copy is retained as a non-secret Container App environment value through the ARM management plane. It lets later workflows clean up superseded vector stores without repeating completed work.
- The user/admin access registry is encrypted with AES-256-GCM using the application session secret and persisted through the Container Apps ARM management plane. It is restored into the local store on every revision.
- Usage events and operational logs use the local JSON store on the single running replica.

Usage/log history is revision-local. The access and administrator registry is durable across revisions. A future analytics phase can add Container Apps VNet integration plus private endpoints and private DNS before enabling Azure Table Storage for long-term audit history.
